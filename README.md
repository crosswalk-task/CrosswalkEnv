# CrosswalkEnv

[![PyPI version](https://img.shields.io/pypi/v/crosswalk-env.svg)](https://pypi.org/project/crosswalk-env/)

A [Gymnasium](https://gymnasium.farama.org/index.html) environment for risky decision-making.

## Requirements

* Python 3.9–3.12

## Installation

```bash
pip install crosswalk-env
```
